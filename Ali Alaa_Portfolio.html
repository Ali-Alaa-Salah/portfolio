About

A bit about how I got here

I'm a Computer Science student at Alexandria Private University with a growing focus on machine learning, data science, and computer vision. Most of what I know beyond the classroom comes from building things — cleaning messy datasets, training models that don't work on the first try, and figuring out why.

Right now I'm going through the Digital Egypt Pioneers Initiative (DEPI), training on the Microsoft Machine Learning Engineer track, which has pushed me from theory into applied work across deep learning, NLP, computer vision, and MLOps.

My approach to a new problem usually starts the same way: understand the data before touching a model. From there it's preprocessing, experimentation, and evaluating what actually works — not just what looks good on paper.

I'm currently focused on strengthening that foundation and building toward internships and early roles in machine learning and applied AI.

Machine Learning · Recommendation Systems

Hybrid Movie Recommendation System

Problem

Recommenders built on a single technique — pure collaborative filtering or pure content-based filtering — tend to struggle with cold-start users and narrow, repetitive recommendations.

Approach

Built a hybrid system combining collaborative filtering via SVD (matrix factorization) with content-based filtering via cosine similarity. Evaluated the SVD model using RMSE and MAE, achieving RMSE 0.8727 and MAE 0.6703.

Technologies

  • Python
  • Pandas
  • NumPy
  • Scikit-learn
  • Surprise

Key Techniques

  • SVD (Matrix Factorization)
  • Cosine Similarity
  • Hybrid Recommendation
  • Model Evaluation (RMSE, MAE)

What I Learned

How blending multiple recommendation strategies compensates for the weaknesses of each individual approach, and how to structure data for a multi-stage recommendation pipeline.

Deep Learning · Computer Vision

COVID-19 Radiography Image Classification

Problem

Medical imaging datasets are often imbalanced across classes, which can bias a classifier toward the majority class.

Approach

Performed EDA and preprocessing on a multi-class chest X-ray dataset (COVID, Normal, Viral Pneumonia, Lung Opacity). Applied image normalization, augmentation, stratified data splitting, and learning-curve analysis. Compared deep learning architectures using validation performance and training behavior.

Technologies

  • Python
  • PyTorch
  • Computer Vision

Key Techniques

  • Image Preprocessing
  • Data Augmentation
  • Stratified Splitting
  • Learning-Curve Analysis

What I Learned

Practical techniques for handling imbalanced datasets in deep learning, and how sampling and loss-function choices shape a model's training behavior.
